RaceDay API

A RESTful API built with ASP.NET Core Web API for managing running, walking, and cycling events. This is the backend for the RaceDay system, handling authentication, event management, enrolments, and results.

 Built With

*   ASP.NET Core 8.0 Web API
*   Entity Framework Core (Code-First)
*   SQL Server (LocalDB)
*   ASP.NET Core Identity (for authentication and roles)
*   xUnit (for unit testing)
*   GitHub Actions (for CI/CD)

Getting Started

Follow these steps to get the API running locally on your machine.

Prerequisites

*   Visual Studio 2022
